# 单页学习页（materials）：资料优先，不重写原理

一页只服务 `current` 那一节，落 `learning/讲义/<YYYY-MM-DD>-<节点标题>.md`。
这一页是**资料索引 + 练习页**，不是教材：原理归来源，页里只做三件事——定位该读哪几段、说清读到什么算够、给三道能验的题。

页首第一行必须是自标，逐字：

> 本页是资料索引与练习页，不是教材；原理以文末来源为准，本节不重写原文。

唯一例外：这一节找不到任何一手来源时，才允许现写原理速览。此时自标换成：

> 本页原理由 AI 现写、未经核实；以文末来源为准，未核实处已标「待核实」。

并且必须写出至少两处「待核实」，在收口时约好下次补一手来源。

第二行逐字抄节点的 `mastery`，并按 §7 按 purpose 变形。

**预算**：正文（不含来源清单与题目）不超过 300 字。超了就是又把教材重写了一遍。

## 1 先给问题

这一节读完要能回答的 2–3 个问题。只列问题，不给答案。

## 2 资料定位（本页主体）

按阅读顺序编号，每条写四件：

- **来源**：`materials[i].ref`（本地文件写相对工作区的路径，链接写 URL）
- **位置**：`materials[i].locator`——章节号 / 页码 / 时间戳 / 段落首句，具体到能一步翻到
- **这段讲什么**：一句人话，不摘抄原文超过一行
- **读到什么算够**：`materials[i].enough` 原样抄

示例：

1. `book`《计算机网络：自顶向下》§3.5.2（p.213–216）——三次握手为什么是三次；读到能画出三段报文交换就停
2. `url` RFC 9293 §3.4 "TCP Connection Establishment"——官方对建连状态机的定义；读到 SYN / SYN-ACK / ACK 各改哪个状态就停

**只定位，不搬运**：不把原文段落贴进来，不把整章内容用自己的话重述一遍。

## 3 读法

- 先读哪一条、哪一条可以跳、遇到不认识的术语去哪查（给一次查法，不解释概念本身）
- 读到卡住时回哪一段
- 一句话说死：先读完资料再回来做 §4，不要边读边对答案

## 4 三道自测题

- 回忆：这一节解决什么问题
- 应用：给一个场景，他该怎么选、怎么做
- 追问：面试官或真实故障会怎么继续往下挖

答案统一放页尾折叠区，读完再对。

## 5 常见踩坑

2–3 条，每条一句"错在哪 + 为什么会这么错"。
这一节 `misconceptions` 里已有的卡壳**必须**在这里出现一条，写成"你上次错在哪"。

## 6 来源

- 一手优先：官方文档、规范、教材章节、课程原始讲义；二手博客不作唯一来源
- 每条写 URL 或路径 + 访问日期 + 一句"它权威在哪"
- 每份来源后面带上节点 `materials[].enough` 那句"读到什么程度算够"
- 资料来自学习者自己的文件时：写文件路径与对应段落位置，不复制原文大段进这一页
- 找不到就直说找不到，**不用"网上有很多教程"糊过去**

## 7 达标动作按 purpose 变形

`mastery` 的形态由 `purpose.kind` 决定，写这一页时把它落成一件真场景里的小事：

| kind | 达标动作长什么样 | 例 |
| --- | --- | --- |
| `job` | 能跑的最小东西，或能在评审里讲清一个取舍 | "不看资料画出三次握手图，并说出第三次防的是什么" |
| `exam` | 限时答对一道真题，并说出考点 | "8 分钟内做对 2023 年第 17 题，说出考的是拥塞控制哪一条" |
| `interest` | 做出一个自己真会用的成品片段 | "给自己的小工具加上重试，断网时不再崩" |
| `career-switch` | 能拿去面试讲的项目片段 + 一句取舍理由 | "在项目里换掉轮询，讲清为什么选 WebSocket 而不是 SSE" |

`purpose.detail` 里的岗位名 / 考试名要真的出现在动作里，别写成通用句。
**禁止**"读完某章""理解某概念""掌握 X"这类不可验证表述。

## 8 复习记录（仅 method: spaced）

页尾固定一行，供下次复习算间隔。格式逐字照抄，不要改标点：

`复习记录：达标日 YYYY-MM-DD；已复习 N 次`

首次生成时 N = 0、达标日写 `待定`；无提示产出达标那天把 `待定` 换成真实日期。
每次复习达标把 N +1，并按 [methods/spaced.md](methods/spaced.md) 更新 `reviewOn`。
JSON 模型里没有复习轮次字段，**这一行就是轮次的唯一载体**。

## 9 批量禁令

学习者要求"把整门课讲义都写出来"时：先说明为什么一次一页（写完这一页要读完、要练到无提示产出，再决定下一节怎么走），然后**只交当前这一页**。

## 10 谁写这一页

- `materials` 里有一手来源 → **只编排**：定位、读法、自测。原理一句都不重写。
- 来源怎么来的不分高低：学习者自己给的、或首次引导里我搜出来推荐的，都算一手来源。
- `locator` 只写真实读到的目录 / 正文；只拿到书名没读到目录，就写「章节待补」，**不许编页码**。写了「章节待补」的这一页，把「位置待补」也标进 §2，别让它看起来像能一步翻到。
- 一条来源都没有 → 才走 §0 的例外：现写速览、标「待核实」、约下次补来源。
- 资料明显不匹配这一节（章节对不上、版本过时）→ 先在 `materials` 里换一条，再编排；不拿错资料硬套。
