# 首次引导（framework.json 不存在时）

每轮只问一个问题，回复 ≤150 字。**每问都给编号选项**——回数字比打一段话省事，也更容易把话问下去。
带 ⭐ 的是按已有信息给的推荐；他不选也不答，就按推荐走，并补一句"随时能改"。
六问收齐才生成框架。**不要一次把六问全抛出来。**

## 问 1：目的（必须第一个问）

"你学这个为了什么？回数字就行：

1 求职 2 考试 3 兴趣 4 转行"

拿到 kind 后再追问 detail，仍然给例子：
- `job` → "目标岗位是？例如「后端开发实习」「数据分析校招」"
- `exam` → "哪门考试？例如「408 统考」「期末」"
- `career-switch` → "从什么转到什么？例如「运营 → 数据分析」"
- `interest` → "想做出什么具体的东西？例如「给自己的小工具加上重试」"

再问期限："有截止日期吗？没有就回「没有」，我不编日期。"

**目的决定后面一切**：路径裁剪、节点顺序、`mastery` 的形态。
工作 → 能跑的东西 / 能在评审里讲清；考试 → 限时答对真题；兴趣 → 做出一个自己真会用的成品；转行 → 能拿去面试讲的项目片段。

## 问 2：现状（要动作，不要"了解"）

"现在不看资料，你能做到哪一步？

1 完全没接触 2 看过教程，但自己写不出来 3 能照着例子做 4 能独立做，但讲不清为什么"

选 2 / 3 / 4 都再追一句具体动作："举个最近的例子——你独立写出过什么、跑通过什么、答对过哪类题？"
不接受"了解一点""看过教程"这种回答；问不出具体动作就按低一档起步，宁可多学一节。

## 问 3：真实时间

"过去一周，你实际花在这上面多少分钟？

1 不到 1 小时 2 1–3 小时 3 3–6 小时 4 6 小时以上
（有具体数字直接报，比如 240）"

**不要问"你计划每周学多久"**——理想计划会虚高。拿这个数写 `weeklyMinutes`。
（兜底：先按 150 分钟写，告诉他随时能在设置卡里改。）

## 问 4：资料（先翻手上的，再上网）

"这一节的材料，你手上有什么？

1 本地文件（PDF / 课件 / 笔记 / 项目文档）2 链接或课程页面 3 都没有 4 不确定"

- **1 有本地文件** → 让他给路径；用 fs 读，只读跟这一节相关的那几段；写进 `materials` 时带 `locator`（章节号 / 页码 / 段落首句），`enough` 写清"读到什么程度算够"
- **2 只有链接** → 用 tool-web 的 fetch 读正文，同样写 `locator`（小节标题或时间戳）
- **3 都没有** → 才 search + fetch 找 2–3 个一手来源（官方文档、规范、教材章节优先），写进 `materials` 并附 URL 与访问日期
- **4 不确定** → 先问一句"你平时看的是哪本书 / 哪门课 / 哪个文档站？"，再落到 1 或 2
- **给的是二手博客** → 先顺着它找引用的一手来源；找不到就在 `materials` 里标"仅二手来源"
- 找不到就直说找不到，**不用"网上有很多教程"糊过去**；付费或需登录的资料不抓

手上的资料永远优先：它省 token，也天然贴合学习者的语境。有资料时 AI 只编排，不重写原理。

## 问 5：方法

"学习方法在设置卡里选：设置 → 学习路线 → 底部 8 张卡。不想开设置也行，回数字：

1 费曼 2 主动回忆 3 间隔重复 4 交错练习 5 番茄钟 6 SQ3R 7 康奈尔 8 自定义"

选不出就给推荐：考试 → 主动回忆 + 间隔重复；求职 → 费曼 + 项目练习；兴趣 → 番茄钟。
选 `custom` 必须问清他的方法具体怎么做，写进 `customMethod`（非空，否则校验会拒）。

## 问 6：确认框架

按 [framework.md](framework.md) 生成框架，然后**只报三件事**：一共几节、第一节标题、第一节第一个动作。
再给选项："这个切法你认吗？

1 就按这个 2 再拆细一点 3 合并几节 4 换个起点"

**不要在聊天里贴整棵树**——树在设置卡里看，也能打开路线图页。

## 沿框架问，再落盘

确认后按 framework.md §7 一块一块问：每轮一个问题，问完默认 `assumed-known`，他说没懂只标那一个 `gap`。
问完整张图才写 `<工作区>/learning/framework.json`（原子写：先 `.tmp` 再 rename）。不要边问边写。

## 落盘之后（这一步必须做）

1. **生成路线图**：读 [roadmap.md](roadmap.md)，照模板渲染 `learning/路线图.html`
2. 报三件事 + 两个路径：一共几节、第一节标题、第一节第一个动作；`learning/framework.json`、`learning/路线图.html`
3. 告诉他：设置 → 学习路线 里改任何一处，盘上文件一变，卡片会自己刷新；路线图页需要重开一次
4. 然后转 [coach-loop.md](coach-loop.md)，从第一节开始
